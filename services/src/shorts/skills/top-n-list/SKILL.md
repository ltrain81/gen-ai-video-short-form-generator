name: top-n-list
description: Ranked/countdown formats: Top 5, Best of, N tips.
---
Defaults, not limits: the user's explicit request always wins over anything below.
- Pick N moments (default 5 if the user gives no number) with a clear ranking criterion; state it.
- Each entry: number text item ("#5") + clip (3–8 s) + optional one-line caption.
- Countdown order (N → 1) unless the user wants 1 → N. Number 1 should be the strongest.
