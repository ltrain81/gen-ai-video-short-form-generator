Defaults, not limits: the user's explicit request always wins over anything below.
- Structure as steps: find step boundaries from transcript/chapters; label each with a "step" text item
  ("1. ...").
- Keep the screen readable: screen recordings in vertical → "letterbox" or zoomed crop on the active UI area
  (`analyze_framing` intent "keep the cursor/active panel readable").
- Speed up waiting/loading parts (`update` speed 2–4) instead of cutting them when continuity matters.
- End with the result and a CTA text item.
