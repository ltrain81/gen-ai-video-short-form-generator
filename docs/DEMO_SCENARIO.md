# AWS Shorts V2 — 데모 촬영 시나리오

> 목표: "한 문장이면 끝나는데, 원하면 끝까지 직접 만질 수 있다"를 6–8분 안에 보여준다.
> 기능을 하나씩 나열하지 않고, **한 편의 이야기(경기 영상 한 개 → 여러 플랫폼용 결과물)** 안에서 기능들이 서로 이어지도록 구성했다.
> 각 장면 옆의 ⏱ 는 실제 테스트에서 측정한 소요 시간이다. 대기 구간은 편집으로 압축(점프컷/배속)한다.

---

## 0. 촬영 전 준비 (D-1)

| 항목 | 내용 | 비고 |
|---|---|---|
| 계정 | 데모용 워크스페이스 1개 (예: "AWS Sports Media"), 관리자 1명 + 편집자 1명 | `scripts/create_user.py`로 생성 |
| 워크스페이스 언어 | 한국어 | 관리 > 워크스페이스 |
| 아카이브 | ① 메인 경기 영상 `SPOTV2.mp4` (17분) ② 강의/키노트 영상 1개 (슬라이드 있는 것) ③ 풍경·B-roll 영상 2–3개 ④ 로고 PNG(투명) ⑤ 인트로 영상 3초 | **전날 업로드해서 분석 완료(준비됨) 상태로** — 17분 영상 분석 ≈ 12분 |
| 브랜드 킷 | "AWS Sports Media": 로고 우상단, 강조색 `#FF9900`, 자막 bold, 인트로 연결 | 라이브러리 > 브랜드 킷 |
| 미리 만들어 둘 것 | 장면 5용 렌더 결과 1개(최종 MP4), 장면 6용 일괄 생성 결과 | 촬영 중 대기 최소화 |
| 화면 | 1440×900 이상, 브라우저 확대 100%, 다크 모드/라이트 모드 각각 1회 촬영 | 테마는 상단 메뉴 |
| 생성 모드 | 장면 7을 찍으려면 `-c mode=full` 배포 + GPU 엔드포인트 한 번 워밍업 | 콜드 스타트 8–15분 → 미리 1회 실행 |

## 장면 1 — 훅 (0:00–0:30) "17분 경기를 한 문장으로"

**화면**: 스튜디오 첫 화면(채팅이 가운데).
1. 레시피 칩에서 **스포츠 하이라이트** 클릭 → 비율 9:16, 길이 45초, 자막 bold 가 자동으로 맞춰지는 것을 보여준다.
2. 첨부 버튼 → 아카이브에서 경기 영상 선택.
3. 입력: **"이 경기의 골 장면만 모아서 45초 세로 하이라이트 만들어줘"** → 전송.

**연출 포인트**: 채팅이 오른쪽으로 밀려나고 왼쪽에 캔버스가 열리는 전환을 그대로 담는다.
**내레이션**: "아카이브에 있는 17분짜리 경기, 프롬프트 한 줄이면 됩니다."

## 장면 2 — AI가 일하는 모습 (0:30–1:30) ⏱ 약 1분

**화면**: 프로젝트 편집기.
1. 채팅에 진행 단계가 실시간으로 바뀌는 모습(프로젝트 확인 → 영상 파악 → 아카이브 검색 → 세로 프레이밍 분석 × 7 → 편집 적용).
2. 타임라인에 클립이 하나씩 채워지고, 프리뷰가 실시간으로 갱신된다.
3. 완료 후 AI 답변: "7골만 시간순으로 편집, 골 장면별 세로 리프레임 적용 …" + 추천 버튼.

**연출 포인트**:
- "작업 N단계 완료"를 펼쳐서 AI가 무엇을 했는지 보여준다 (검색 → 화면 보기 → 프레이밍).
- 타임라인 클립에 마우스를 올려 **AI가 고른 이유**("선제골: 래시포드의 득점과 직후 세리머니로 강하게 시작합니다") 툴팁을 보여준다 → *설명 가능한 AI 편집*.
- 프리뷰를 재생하면서 **크롭이 선수를 따라가는 클립**과 **블러 배경으로 전체를 보여주는 클립**이 섞여 있는 것을 강조.

**내레이션**: "AI가 영상을 이해하고(Pegasus), 장면을 찾고(Marengo), 세로 화면에서 무엇을 살릴지 직접 보고 결정합니다."

## 장면 3 — 말로 다듬기 (1:30–2:10) ⏱ 약 25초

1. 추천 버튼 대신 직접 입력: **"골마다 득점자 이름 자막을 넣어주고, 템포를 조금 더 빠르게 해줘"**
2. 타임라인 텍스트 트랙에 득점자 이름이 채워지고 전체 길이가 41초로 줄어드는 것을 보여준다.
3. 이어서 타임라인에서 3번째 클립을 클릭 → 채팅 입력창에 **"선택됨: …" 칩**이 붙는다 → **"이 장면은 좀 더 길게 보여줘"**

**연출 포인트**: "가리키고 말하기" — 클릭한 클립이 대화의 맥락이 된다.

## 장면 4 — 직접 편집으로 전환 (2:10–3:30) "원하면 끝까지"

1. 상단 **AI / 직접 편집** 토글을 **직접 편집**으로.
2. 2번째 클립 오른쪽 끝을 드래그해 트림 → 📌 핀이 붙고 뒤 클립들이 자동으로 당겨진다(마그네틱 트랙).
3. 속성 패널: 세로 레이아웃을 **크롭 → 블러 배경 → 분할**로 바꿔보며 프리뷰가 즉시 바뀌는 것.
4. 클립 하나에 전환 **dissolve** 지정, 재생 위치에서 **S**로 분할, **⌘Z** 실행 취소 / 다시 실행.
5. **추가** 탭 → 브랜드 킷 "AWS Sports Media" **적용** → 우상단 로고, 인트로, 자막 색이 한 번에 바뀐다.
6. 다시 **AI** 모드로 전환 → **"전체적으로 30초로 줄여줘"** → AI가 줄이되 **핀 고정된 내 편집(트림, 레이아웃)은 그대로 둔다**. 속성 패널의 "고정됨" 목록으로 확인.

**핵심 메시지(자막으로 띄우기)**: *AI와 사람이 같은 타임라인을 편집한다. 내가 손댄 건 AI가 건드리지 않는다.*

## 장면 5 — 게시 준비와 내보내기 (3:30–4:30) ⏱ 렌더 약 3.5분 (미리 만든 결과 사용)

1. 속성 패널(선택 해제 상태) → 게시 정보 **AI 추천** → 제목·설명·해시태그가 한국어로 채워진다.
2. 프리뷰를 원하는 장면에 두고 **현재 프레임을 썸네일로**.
3. **내보내기 → 최종 렌더 (MP4)** → 렌더 결과 창에서 진행률 → (컷) → 완료된 렌더의 MP4 재생, SRT 다운로드.
4. **내보내기 → FCPXML** 다운로드 → (선택) DaVinci Resolve/Premiere에서 열어 같은 컷이 열리는 것을 3초 보여준다.

**내레이션**: "1080×1920, 자막 번인, 음량 -14 LUFS 정규화까지 서버에서 렌더링됩니다. 더 다듬고 싶으면 프로 편집 툴로 그대로 넘깁니다."

## 장면 6 — 한 번에 여러 개 (4:30–5:30) ⏱ 3개 약 2분

1. 스튜디오로 돌아가 같은 경기 영상 첨부 → **"이 영상으로 숏폼 여러 개 만들기"** 토글 → 개수 3, 레시피 스포츠, 브랜드 킷 선택.
2. 일괄 생성 화면: 카드 3개가 동시에 "AI 작업 중" → 완료.
3. 결과: **라인업 / 전반전 2골 / 후반전 대역전극** — 겹치지 않는 3편, 모두 로고 적용.

**연출 포인트**: 세 카드를 빠르게 열어 서로 다른 구간을 쓰는 것을 보여준다. "17분 영상 → 3개 쇼츠, 2분."

## 장면 7 — 아카이브에 없으면 만든다 (5:30–6:30, 생성 모드) ⏱ 이미지 약 25초 / 영상 약 7분 (워밍업 후)

1. 강의 영상 프로젝트에서 **"이 강의를 60초 세로 클립으로 만들고, 서버리스 개념을 설명하는 장면에는 B-roll을 넣어줘"**
2. AI가 아카이브를 검색하고 "적합한 B-roll이 없다"고 말한 뒤, **예상 비용·시간이 표시된 확인 카드**를 띄운다 → **예** 클릭.
3. (컷) 생성된 이미지/영상이 **AI 생성 표시**가 붙은 아카이브 자산으로 들어오고, B-roll 트랙에 배치된다.
4. 강의 슬라이드 장면은 **분할 레이아웃**(위 화자 / 아래 슬라이드)으로 되어 있는 것을 보여준다 — *강의는 대사·슬라이드 중심, 풍경은 영상 중심으로 AI가 다르게 편집한다.*

**주의**: 실존 인물 사진은 참조로 쓸 수 없다는 안내가 나오는 장면을 보여줘도 좋다(안전장치).

## 장면 8 — 아카이브와 협업 (6:30–7:30)

1. **아카이브**: 검색창에 **"관중이 환호하는 장면"** → 일치 구간(시각/대사/설명)과 썸네일, 클릭하면 해당 시점부터 재생.
2. **이미지로 검색**: 로고/선수 사진을 올려 비슷한 장면 찾기.
3. 자산 상세: 챕터 · 장면 · 대본 탭, **공유** → 그룹 "편집팀"에 *사용자(편집에 사용, 원본 다운로드 불가)* 권한, 만료일 지정.
4. **라이브러리 > 스킬**: 기본 스킬 "sports"를 **복제해서 수정** → "우리 팀은 골 직전 5초를 꼭 포함" 한 줄 추가 → 다음 편집부터 AI가 이 규칙을 따른다.

## 엔딩 (7:30–8:00)

- 라이트 ↔ 다크 모드 전환 한 번, 영어 UI 전환 한 번.
- 아키텍처 그림(`docs/architecture/architecture-dark.png`) 3초.
- 마지막 자막: *"기본은 아주 쉽게, 원하면 끝까지 깊게 — AWS Shorts V2"*

## 촬영 팁

- 대기 구간(분석·렌더·생성)은 미리 만든 결과로 컷하고, 진행 표시만 2–3초 보여준다.
- AI 응답은 매번 조금씩 다르다. 장면 2–3은 2회 이상 찍고 좋은 테이크를 쓴다.
- 채팅 입력은 미리 복사해 두고 붙여넣는다(타이핑 오류 방지). 단, 장면 1은 직접 타이핑하는 쪽이 자연스럽다.
- 브라우저 알림/북마크바 숨김, 마우스 커서 하이라이트 켜기.
